# MTB Bikes - Навчальний вебпроєкт

Лабораторна робота № 5-6: «Організація середовища розробки. Git, GitHub та структура проєкту».

## Опис проєкту
Простий навчальний адаптивний вебсайт на тематику гірських велосипедів (MTB).  
Створений за допомогою чистих технологій: HTML5, CSS3 та JavaScript.


## Використані технології
- **HTML5:** семантичні теги (`header`, `nav`, `main`, `section`, `article`, `footer`).
- **CSS3:** Flexbox (шапка, картки), CSS Grid (сітка каталогу, контакти), адаптивність (Media Queries).
- **JavaScript:** мобільне бургер-меню, фільтрація за категоріями, модальне вікно, перевірка форми.
- **Git & GitHub Pages:** версіонування та публікація.
